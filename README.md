# 💬 Flutter Chat App

A modern real-time chat application built using Flutter. The app provides secure authentication, real-time messaging, and a clean user interface for seamless communication.

---

## ✨ Features

- 🔐 User Authentication
- 💬 Real-time Messaging
- 👤 User Profiles
- 📱 Clean & Responsive UI
- ⚡ Fast and Smooth Performance
- 🎨 Material Design Interface

---

## 🛠 Tech Stack

- Flutter
- Dart
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Material Design

---

## 📂 Project Structure

```
lib/

```

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/flutter-chat-app.git
```

### Install dependencies

```bash
flutter pub get
```

### Run the application

```bash
flutter run
```
